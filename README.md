# 📊 Social Media Sentiment Analysis Dashboard

## 📌 Project Overview

The Social Media Sentiment Analysis Dashboard is a Machine Learning and NLP-based project that analyzes customer sentiment from social media comments, reviews, and posts.

This system classifies text into:
- 😊 Positive
- 😡 Negative
- 😐 Neutral

The project also provides a professional interactive dashboard using Streamlit for real-time sentiment analysis and visualization.

---

# 🚀 Features

✅ Text preprocessing and cleaning  
✅ Stopword removal using NLTK  
✅ TF-IDF feature extraction  
✅ Logistic Regression ML model  
✅ Real-time sentiment prediction  
✅ Positive / Negative / Neutral classification  
✅ KPI dashboard cards  
✅ Sentiment distribution charts  
✅ Pie chart visualization  
✅ Word Cloud visualization  
✅ CSV upload for bulk sentiment analysis  
✅ Download prediction results

# 📥 Installation

## Clone Repository

```bash
git clone https://github.com/YourUsername/Social-Media-Sentiment-Analysis-Dashboard.git
```

---

## Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Project

## Run Dashboard

```bash
streamlit run app/dashboard.py
```
